# Sultan Simple TV

نسخة بسيطة جدًا لتشغيل القنوات على Android TV.

## ماذا أضفت في هذه النسخة؟
- فتح ملف M3U من الجهاز أو USB.
- تحميل قائمة M3U من رابط URL.
- قراءة أسماء القنوات و `group-title` تلقائيًا.
- حفظ القنوات داخل التطبيق بعد الاستيراد.
- يدعم القوائم الكبيرة عبر قائمة قابلة للتمرير بالريموت.
- زر OK يشغّل القناة بملء الشاشة.
- أثناء البث: أعلى/أسفل يغيّر القناة.
- زر الرجوع أو OK أثناء البث يرجع إلى قائمة القنوات.
- زر "مسح" يرجع إلى البث التجريبي فقط.

## إضافة كل قنواتك
بدل تعديل الكود قناة قناة، جهّز ملف M3U يحتوي القنوات التي لديك حق استخدامها، مثل:

```m3u
#EXTM3U
#EXTINF:-1 group-title="أخبار",قناة الأخبار
https://example.com/news.m3u8
#EXTINF:-1 group-title="أطفال",قناة الأطفال
https://example.com/kids.m3u8
```

ثم من التطبيق اختر:
- **فتح ملف M3U** لفتح ملف محلي، أو
- **رابط M3U** للصق رابط قائمة القنوات.

> التطبيق لا يأتي بروابط قنوات تجارية أو مدفوعة غير مصرّح بها. استخدم فقط روابط البث التي تملك حق الوصول إليها.

## فتح المشروع
1. افتح المجلد في Android Studio حديث.
2. دع Android Studio يعمل Gradle Sync.
3. شغّل التطبيق على Android TV Emulator أو جهاز Android TV.
4. لإنشاء APK: من قائمة Build اختر Build APK(s).

## ملاحظات
- المشروع يستخدم Media3 ExoPlayer لتشغيل البث.
- تم السماح بروابط HTTP القديمة لأن بعض قوائم M3U ما زالت تستخدمها، لكن HTTPS أفضل كلما كان متاحًا.
